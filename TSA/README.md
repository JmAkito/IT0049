# SwiftPOS CodeIgniter Application

SwiftPOS is a basic Point-of-Sale account management application built with CodeIgniter 4 and MySQL. It demonstrates the MVC architecture, routing, database configuration, models, Query Builder, controllers, and views.

## Features

- Landing page
- About page
- Customer Accounts page
- User Accounts page
- MySQL database connection
- CustomerModel and UserModel
- Database records retrieved using `findAll()`
- Responsive navigation and account tables

## Requirements

- PHP 8.1 or newer
- Composer
- XAMPP with Apache and MySQL
- CodeIgniter 4
